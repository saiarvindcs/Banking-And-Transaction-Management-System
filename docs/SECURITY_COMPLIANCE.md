# Security and compliance work plan

This is an educational simulator. No real personal banking data, real card PAN, account credentials, or funds should be used.

Required before any production claim: threat modeling, OWASP ASVS/API Top 10 assessment, MFA enforcement, fine-grained RBAC, maker-checker separation, rate-limit enforcement at ingress, KYC/AML vendor and legal review, RBI applicability assessment, privacy/retention policies, tamper-resistant audit trails, cryptographic key management, secrets rotation, penetration test, vulnerability management, backup/PITR and restore drill, HA failover drill, SLO/SLI monitoring, incident response tabletop, DR RPO/RTO testing, external audit and applicable licensing. A compliant implementation requires qualified legal and security review.
